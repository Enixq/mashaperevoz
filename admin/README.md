# Локальная админка

Открывайте `admin/index.html` через локальный веб-сервер.

Это автономный шаблон: он не использует Supabase, Telegram, авторизацию или серверную базу данных. Демо-заявки, карточки работ и контакты хранятся только в `localStorage` браузера.

Разделы:

- `Заявки` — создание, редактирование, статусы и удаление тестовых заявок.
- `Работы` — локальные карточки для блока «Решения для участка».
- `Настройки` — телефон, email и название проекта.

Чтобы подключить настоящие заявки позже, нужно заменить localStorage-слой в `admin/admin.js` на серверный API или базу данных и отправлять форму сайта в этот же API.
