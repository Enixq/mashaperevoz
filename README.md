# Вокруг участка

Лендинг для комплексных работ на участке: доставка строительных материалов, вывоз мусора, демонтаж, монтаж и реставрация заборов.

## Публикация

Сайт подготовлен для GitHub Pages. Основные файлы находятся в корне:

- `index.html`
- `styles.css`
- `script.js`
- `assets/`

В GitHub Pages включите `Settings` → `Pages` → `Deploy from a branch` → `main` → `/ (root)`.

После публикации адрес будет иметь вид:

```text
https://enixq.github.io/mashaperevoz/
```

## Форма заявки

GitHub Pages не запускает PHP. Файл `send.php` намеренно исключён из публикации. Для рабочих заявок нужно подключить внешний сервис форм или разместить сайт на PHP-хостинге.
