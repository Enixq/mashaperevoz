# Вокруг участка — сайт + CRM-админка

## Возможности

- Публичный сайт с формой заявок и загрузкой фото.
- SQLite-база в `data/site.sqlite`.
- Вход по логину и паролю, сессионная cookie.
- Роли:
  - **Главный админ** — сотрудники, роли, заявки, работы и контакты.
  - **Менеджер** — заявки и карточки работ.
  - **Сотрудник** — только назначенные ему заявки.
- Главный админ назначает ответственных по заявкам и создаёт новых пользователей через `/admin/`.

## Первый запуск

1. Отредактируйте `.env`:

```env
PORT=8017
HOST=127.0.0.1
ADMIN_USER=admin
ADMIN_PASSWORD=длинный-уникальный-пароль
```

2. Запустите:

```bash
npm start
```

3. Откройте:

- сайт: `http://127.0.0.1:8017/`
- админка: `http://127.0.0.1:8017/admin/`

При первом старте автоматически создаётся главный администратор из `ADMIN_USER` и `ADMIN_PASSWORD`.

## Размещение

Для нормальной работы нужен Node.js 24+ и постоянное хранилище диска для `data/site.sqlite` и `uploads/`. GitHub Pages для этой версии **не подходит**.

Для VPS используйте Nginx как reverse proxy и systemd-сервис из `deploy/`.
