# ТЕРРА — одностраничный сайт

Лендинг для услуг по доставке материалов, вывозу мусора, демонтажу, монтажу и реставрации заборов.

## Что загружать на GitHub Pages

Загрузите эти файлы и папки:

- `index.html`
- `styles.css`
- `script.js`
- `assets/` (папка, даже если сейчас она пустая)

Файл `send.php` на GitHub Pages не работает: GitHub Pages размещает только статические файлы и не выполняет PHP. Его можно использовать только на обычном PHP-хостинге. До подключения обработчика форма на GitHub Pages визуально работает, но данные не будут доставляться заказчику.

## Публикация через GitHub Pages

1. Откройте `https://github.com` и войдите в аккаунт.
2. Нажмите `+` в правом верхнем углу, затем `New repository`.
3. В поле `Repository name` укажите, например, `terra-landing`.
4. Выберите `Public`.
5. Не включайте `Add a README file`, если загружаете этот проект целиком.
6. Нажмите `Create repository`.
7. На странице нового репозитория нажмите `uploading an existing file`.
8. Перетащите в окно GitHub `index.html`, `styles.css`, `script.js` и папку `assets`.
9. Внизу страницы нажмите `Commit changes`.
10. Откройте вкладку `Settings` → `Pages`.
11. В блоке `Build and deployment` выберите `Deploy from a branch`.
12. Укажите ветку `main` и папку `/ (root)`, затем нажмите `Save`.
13. Через 1–3 минуты сайт будет доступен по адресу:
    `https://ВАШ_ЛОГИН.github.io/terra-landing/`

## Как сделать форму рабочей

GitHub Pages не умеет принимать заявки самостоятельно. Есть два варианта:

- разместить сайт на PHP-хостинге и загрузить туда также `send.php`, задав переменную `SITE_RECIPIENT_EMAIL`;
- подключить внешний сервис форм, например Formspree или аналогичный сервис, и заменить в `index.html` значение `action="send.php"` на адрес формы из этого сервиса.

Для собственного домена его можно подключить в `Settings` → `Pages` → `Custom domain`.
